# UI fonts

Self-hosted Latin subsets generated by `scripts/vendor_fonts.py` from Google Fonts:

- Newsreader (SIL Open Font License 1.1)
- IBM Plex Sans (SIL Open Font License 1.1)
- IBM Plex Mono (SIL Open Font License 1.1)

The browser falls back to system fonts for scripts not covered by these subsets.
