# Globe boundary textures

`earth-light-boundaries-{4k,8k}.webp` and `earth-dark-boundaries-{4k,8k}.webp`
are generated by `scripts/build_boundary_textures.py`:

```bash
pip install -r scripts/requirements.txt
python scripts/build_boundary_textures.py
```

Sources, all public domain:

- Natural Earth 1:50m Admin 0 Countries
- Natural Earth 1:10m Admin 1 States/Provinces
- Natural Earth 1:10m Admin 0 Disputed Areas
- Natural Earth 1:50m Admin 0 Boundary Lines, Disputed Areas
- NASA Blue Marble Next Generation (21600 × 10800 day mosaic)
- NASA Black Marble 2016 (night lights mosaic)

The 8k texture is used when the GPU supports textures at least 8192 px wide;
otherwise the 4k version is served. Boundaries are de facto lines. Disputed
areas are shown with a translucent tint and dashed claim boundaries; they are
not assigned to one sovereign party. The Atlas map key states the same policy in
the app; disputed areas are never assigned to one claimant.

## Label layers

`country_labels.json` and `admin1_labels.json` are generated by
`scripts/build_label_data.py`. Country labels use Natural Earth's cartographic
`LABEL_X`/`LABEL_Y` points; state labels use the Natural Earth admin-1 centre
coordinate. The frontend loads country labels first and lazy-loads state labels
only at regional zoom, then filters them to the visible part of the globe.
